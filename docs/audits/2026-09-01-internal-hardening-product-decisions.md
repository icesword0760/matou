# Matou 内部版健壮性改造：产品决策定稿

- 决策日期：2026-09-01
- 依据报告：`docs/audits/2026-09-01-internal-hardening-analysis.md`
- 实施工作树：`/Users/icesword/Documents/AIProjects/matou/.worktrees/internal-hardening-audit`
- 实施分支：`codex/internal-hardening-audit`

## 总体原则

1. 会话、会话历史和会话关系属于用户资产；PTY、xterm、Worktree 和工作目录属于可恢复的运行环境。
2. 环境异常不改变会话资产状态，也不静默切换到其他目录继续执行。
3. 当前工作现场优先可交互；其他会话按状态和优先级在后台有界恢复。
4. 已确认 Mockup、PRD 和 Kooky CLI 黑色工作区内的用户可感知行为继续作为验收基线。

## D-01｜前台与后台会话

- 当前横向会话列表中的全部会话都属于前台，包括已经横向滑出视野的会话。
- 非活动页签、其他事项、其他工作空间、最小化或隐藏窗口，以及只存在于 DAG 中但尚未打开的会话属于后台。
- 前台会话保留 PTY 与 xterm；后台会话保留 PTY 运行，但解除 xterm 渲染绑定，重新进入时从 checkpoint/journal 补齐画面。

## D-02 / D-03｜启动与场景恢复

- App 先恢复当前工作空间、当前事项、当前场景和活动会话，使用户尽快进入工作现场。
- 其他此前处于运行中或等待输入的会话进入有界恢复队列；显式停止的会话保持停止，已删除的会话保持删除。
- Shell 恢复 cwd、已完成命令和历史；崩溃时尚未完成的 Shell 命令标记为已中断，不自动重跑。
- Claude Code 使用原 provider session 自动恢复。
- 每个正在恢复的会话卡片显示覆盖完整卡片区域的 Loading，展示恢复阶段，恢复期间阻止该卡片操作；完成后淡出，失败时提供重试或移除入口。

## D-04｜终端历史保留

- Claude Code 自身的会话历史、上下文和恢复机制不受 Matou 终端可见历史上限影响。
- Matou 即时恢复每个会话最近 10,000 行终端内容。
- 更早输出进入压缩、可搜索的归档。
- 每个会话的 raw Journal 初始上限为 256 MB，配合轮转、压缩和索引。

## D-05｜数据库只读与损坏

- 数据库只读时进入明确的只读恢复模式，可浏览、搜索、复制和导出；写操作显示禁用原因。
- 数据库损坏时进入恢复页面，不直接呈现全新空状态。
- 正常退出及 schema migration 前生成 SQLite 备份，保留最近 7 份。
- 只有用户明确选择后才进入全新空状态。

## D-06｜Worktree 与会话环境

- 会话与 Worktree 分离：Worktree 消失后，会话、历史和 DAG 关系仍然保留且可查看。
- Worktree 缺失时不静默回退到 workspace root 或 HOME；继续输入前先完成恢复、定位或 Handoff。
- 右下角显示两个独立状态：运行环境（Local / Worktree / 待恢复 / 交接中）与 Git 状态（分支或 detached HEAD、未提交标记）。
- 运行环境入口支持查看路径、Finder/终端打开、恢复、定位，以及在当前会话绑定的 Local 与 Worktree 之间 Handoff。
- 一个会话只绑定一个独立 Worktree；选择其他 Worktree 时切换到其对应会话，而不是重绑当前会话。
- 用户触发实际恢复或交接后，卡片进入全区域 Loading 状态。

## D-07｜存储写入失败

- 首次持久化失败后，只暂停受影响会话的执行进程，保留会话资产和进程状态；其他会话继续运行。
- 显示存储异常、重试与结束会话入口，并保留尚未写入的最后一段有界输出。
- 存储恢复后从失败位置继续持久化并恢复执行。
- Claude Code 网络连接若已过期，恢复原 Claude Session。

## D-08｜DAG 远层展示

- 当前节点和附近层级完整展示，远层按分支或层聚合。
- 聚合节点展示包含的会话数量，以及运行中、待输入、失败等状态计数。
- 点击、缩放进入或搜索命中时展开并定位目标。

## D-09｜移除节点

- 只保留统一的“移除节点…”入口。
- 弹窗让用户选择“仅移除当前节点”或“移除当前节点及全部后代”。
- 弹窗明确展示受影响的会话和 Worktree 数量。
- PRD、Kooky 对照矩阵和旧 E2E 合同同步更新为此语义。

## D-10｜App 回焦

- 返回 Matou 时恢复离开前的焦点：终端、重命名输入、搜索、Fork 输入或确认弹窗。
- 原控件已经关闭时聚焦当前活动终端。
- Claude Code 回答完成时保持用户当前焦点；新增会话或窗口完成后自动聚焦新终端。

## D-11｜Fork / Worktree 长任务

- 移除固定 10 秒失败判断，持续显示创建、应用修改、初始化环境、恢复 provider、启动窗口等阶段进度。
- 创建过程可以在后台继续，当前阶段暂不提供取消。
- 同一个 Fork 进行中时禁用重复提交。
- App 重启后对账并继续原创建任务；完成或失败后发送通知。
- 失败时提供重试和残留 Worktree 清理入口。

## D-12｜通知保留

- 每个工作空间最多保留 1,000 条通知。
- 已读普通通知保留 30 天。
- 未读通知保留到用户查看；待输入、待恢复、运行失败等状态型通知在问题解决后转为普通已读记录。
- 达到限制时优先清理最旧、已读、已解决的通知；清理通知不删除会话或终端历史。

## D-13｜大段粘贴

- 对齐 Kooky：粘贴后立即进入终端，不显示大小确认。
- 底层按 UTF-8 安全边界透明分块，中文、Emoji 与 bracketed paste 边界保持完整。
- 分块有序发送，不再因单消息超过 1 MiB 静默丢弃。

## D-14｜拖入终端的路径

- 普通路径保持原样；仅包含空格时保持 Kooky 的双引号形式。
- 出现 Shell 特殊字符时使用当前 Shell 对应的安全引用。
- 多文件保持选择顺序；路径只进入输入区，不自动执行。

## D-15｜终端 Resize

- Resize 按屏幕帧率合并，每帧最多一次，目标约 60 Hz。
- cols/rows 未改变时去重；拖动或动画结束后立即提交最终尺寸。
- 保持 Kooky 已确认的动画时长、运动轨迹和用户感知反馈。
