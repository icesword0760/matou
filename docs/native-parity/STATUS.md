2. `migrate(&mut Connection, applied_at: i64) -> Result<MigrationReport>`: ordered frozen migrations, reject newer schema/checksum mismatch, accept existing legacy checksums and update history names/checksums exactly as source. Preserve optional fields and defaults from source; no event bus, async framework or new retry layer.
