# 供应商添加与切换交付记录

日期：2026-10-14；目标版本：0.2.8，本地 macOS arm64 验收包。

## 用户能完成的操作

入口：设置 → 服务供应商 → Claude Code / Codex → 新增供应商。

1. 先选择服务：官方已有登录、DeepSeek、GLM、Kimi、MiniMax，或自定义。支持搜索与分类，不再先面对空白配置表。
2. API 接入以密钥为主输入，预填地址与模型；“获取密钥”在默认浏览器打开对应官方控制台。
3. “获取模型”直接使用本次草稿，不强迫先保存。可搜索选择，也可手填；返回列表不等于对话实测成功。
4. 更多设置真实展开，可改显示名称和 Claude 三个模型档位映射。编辑保留已有密钥，变更目标地址要求重新填密钥。
5. “仅保存”保持当前供应商；“添加并使用”更新默认。已有供应商直接点“切换”。运行中会话是否已更新按实际结果分别展示，不用一个成功提示掩盖部分未生效。
6. 失败保留草稿，可重试。保存成功但切换未确认时提示核对默认状态，无需重复添加。编辑删除有确认，当前配置禁止删除。
7. 关闭/返回时保护未保存输入；键盘焦点、Escape、固定底部操作区、小窗口滚动均覆盖。

范围说明：此功能切换 CLI 的服务来源，不切换 Chrome 扩展或 Claude 桌面 App 身份；官方账户管理仍走右下角独立入口。

## 复用而非重写

- 预设数据取自当前上游 `https://github.com/farion1231/cc-switch`，固定 commit `6b4c09aca28cbf5357121814314011d7a203675a` 的 Claude/Codex 预设文件，保留 MIT 授权于 `packages/contracts/third-party/provider-presets-LICENSE`，随包分发。
- 使用四组精选地址、默认模型和 Claude 档位映射，不复制完整供应商目录、代理/故障转移引擎、推广链接或与 Matou 无关的 env 配置。预设是快照，可编辑；账户权限和协议支持以供应商实际服务为准。
- 本机 DSH 的模型设置源码仅作为交互参照：先密钥、折叠高级项、草稿获取模型。未使用本机旧版供应商切换应用作为基线。
- 存储、供应商激活、会话绑定/续接、跨窗口同步复用 Matou 原有底层。新增模型查询复用 runtime 网络能力，限定超时/响应大小，不跟随携密钥重定向，不展示上游错误响应正文。
- 0.2.7 账户重新登录修复保留，未改写上游账户切换引擎。

## 建议验收路径

1. 新增 → 任一预设 → 填入你自己的 API Key；确认推荐配置和获取密钥入口。
2. 获取模型，或手填；点“仅保存”，确认当前服务未变。
3. 对已保存服务点“切换”，核对默认标记以及是否有会话暂缓提示。
4. 编辑配置、展开模型映射；填入错误密钥测试失败提示与草稿保留。
5. 小窗口下滚动表单，确认保存按钮始终可用。
