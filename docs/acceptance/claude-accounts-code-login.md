# Claude 添加账户：自动返回与授权码流程

日期：2026-10-14；版本：0.2.6，本地 macOS arm64 验收包。

## 用户可见变化

- 添加账户后，浏览器授权自动返回时直接进入核对与保存。
- 浏览器停在“身份验证码”页面时，在 Matou 等待页粘贴完整授权码，点击“完成登录”（支持 Enter）。提交后显示核对进度；实际登录成功才进入账户保存。
- 输入使用密码样式，关闭面板或提交后清空输入；关闭面板仍保留本次登录进度，重新打开可继续。
- 错误格式留在当前步骤并提示；过期授权可重新登录；旧流程的授权码提交不会进入新登录进程。
- 成功、取消、超时、退出应用均只结束后台登录流程，隐私窗口由用户自行关闭。不会关闭用户原浏览器或既有网页。
- 新账户保存保持现有默认账户不变，切换仍是独立操作。

## 复用边界

继续使用固定版本 claude-swap 0.27.0b1 保存、识别、切换账户；官方 Claude Code 负责 OAuth 校验和凭据交换。新增部分仅将本次流程输入转交给现有 `claude auth login` 的 stdin，没有另写授权交换。

授权码不写入日志、磁盘、命令行参数或账户状态；不自动读取剪贴板。每次登录绑定唯一标识并只接收一次提交。浏览器使用独立 OS 临时配置目录，和待保存凭据目录分离，防止流程清理影响仍在使用的窗口。流程结束时已经关闭的临时浏览器目录会清理；结束后才由用户关闭的窗口，其临时目录留待系统或用户清理。

## 用户验收

1. 底栏账户入口 → 添加账户 → 打开独立隐私窗口。
2. 登录新账户：自动返回则直接核对；如出现授权码，复制完整内容回 Matou，粘贴并点“完成登录”。请使用本次新流程生成的码。
3. 核对身份并保存，确认原默认账户保持不变。
4. 验证登录完成、取消或等待超时后，隐私窗口仍由你自行关闭。
