# Claude 账户：本地切换、官方续期（0.2.15）

## 用户体验与边界

- 账户入口、确认弹框、立即切换、记住范围、切换后的可选立即重启保持原样；切换不自动重启或中断现有任务。
- 登录与重新登录继续使用官方 CLI，自动回调和粘贴授权码均保留；隐私浏览器窗口仍由用户自己关闭。
- 账户管理进程不再发出身份查询、用量查询、OAuth 续期请求。没有伪装请求头，官方 CLI 未修改。
- 切入过期 access token、且 refresh token 有效的账户后，由正在使用它的官方 CLI 续期。失效/撤销的 refresh token 仍需要登录，服务端封禁不由本地切换解决。
- 未使用账户保留上次用量及记录时间。重置日期使用官方原始时间戳；到了日期仅提示「已到重置时间，待更新」，不把旧值当作实时值，不制造 0%，不自行向后加 5 小时/7 天。
- HUD 中上下文、模型、工具、会话状态仍是原会话的信息；账户用量取当前默认账户的缓存。没有记录时显示「使用后更新用量」。
- Keychain 热读取缓存仍由官方版本决定。旧进程在切换后的缓存过渡期可能继续用原账户发请求；已发出的请求不被改写。
- 为避免串号，旧进程的用量要等 35 秒缓存余量后开始的新一轮输入、且产生新的官方 API 响应才记入新账户。仅重绘状态栏、时间经过、旧任务结束都不足以归属新账户。这是用量记录保护，不是对切换或执行任务的等待门禁。新启动的 CLI 可记录首次响应。
- 仅在外部终端使用账户时，Matou 没有收到该终端的 statusLine，就继续显示已有记录。无 statusLine rate_limits 的旧 CLI 版本也只显示已有记录。

## 保留与变更

继续复用固定版 claude-swap 的账户槽位、Keychain / 文件回退、凭据锁、配置锁、MCP 合并、备份、事务回滚。旧账户无需重新录入；不迁移已有登录或切换到永久独立 profile。

`local_engine.py` 仅增加离线策略：跳过远程身份探测，旧用量只读，不申请抓取或消耗 refresh grant。已知属于其他槽位的本地 token family 不写入当前槽位。完整的官方 token rotation 在切出时按官方配置身份保存，写入仍在上游兼容锁保护下。离线策略不再用远端 oracle 证明人为篡改/跨机器错误配对的凭据归属。

Sidecar 的 Python audit hook 阻止出站 socket，防止将来升级引入隐式联网路径；这不是给官方 CLI 子进程加网络限制。封装层没有修改依赖环境中的源码。

官方 statusLine 的用量经 Runtime 本地 IPC 保存到账户 preferences，内容只有账户 ID、比例、观测时间和重置时间，不含凭据。每 5 秒收集本地观测，切出和正常退出前再保存；每分钟仅重读本地账户状态以发现外部登录变化。异常退出最多损失尚未落盘的最近观测，不影响已保存登录。

## Reference product 交互对照矩阵

基线为固定版本上游真实代码、已有 Matou 0.2.14 交互及用户此次明确批准的离线差异；不是以假想界面代替现有实现。

| 场景 | 原有基线 | 本次实际结果 | 结论 |
|---|---|---|---|
| 任务运行中切换 | 上游直接改默认凭据，Matou 主按钮立即切换 | Electron 可见/隐藏会话均保留 PID；继续保留立即重启确认 | 保持 |
| 官方在续期中切换 | 上游兼容 CLI 的 refresh/config 锁 | 真实 Keychain 测试等待该次续期锁约 2.7 秒，保存新 token 后切出 | 保持互斥，不等待任务结束 |
| 续期后的再次切入 | 应保存最新 token pair，避免重新用已消费 grant | 两个 CLI 总共一次 B 续期，再次切入 B 后都接续原历史 | 通过 |
| 续期/查询主体 | 旧管理层主动查询或续期 | 仅官方 CLI；Python 源码断言与打包侧 OS 禁网验证 | 按批准规格变更 |
| 用量与日期 | UI 有 5 小时/周用量、记录时间 | 结构原样；使用官方缓存，过期窗口标明待更新 | 按批准规格变更 |
| 添加、授权码、重新登录 | 官方 CLI + 手工回退，不关闭浏览器 | Electron 自动/手工/错误身份/取消/重试均通过 | 保持 |
| 写入失败 | 上游事务回滚 | 真实 Keychain 注入配置写入失败，原凭据和配置恢复 | 通过 |
| 紧凑窗口/负载/焦点 | 原账户弹层与快捷入口 | 820×560、中英文、三个持续输出终端、关闭返回焦点回归通过 | 保持 |
