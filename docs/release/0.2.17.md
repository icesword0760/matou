# 码头 Matou 0.2.17

## 更新内容

- 码头里运行的 AI 助手调用码头控制命令（新开会话、读取其他卡片等）不再在会话开启 24 小时后失效；会话开着就一直可用，会话结束、卡片移除或码头重启后自动失效。

## 验证与已知限制

- 类型检查、命名检查、桌面 861 项单元测试及 3 项性能测试通过；Contracts 68 项、Domain 7 项和命名门禁 4 项测试通过。开发构建通过。
- 通行证专项 7 项通过，覆盖受管 Shell、Claude Code、Codex 会话启动 7 天后仍可用、移除与真实进程退出后失效、日志写入故障时即时撤销、启动失败回收、Runtime generation 隔离及其他短期通行证仍按时过期。
- Runtime 常规测试 1149 项通过、1 项跳过、1 项失败；RuntimeServer 136 项通过、1 项失败；历史范围读取最后一次完整运行 7 项通过、2 项失败。不能视为 Runtime 全套通过。
- 既有日志用例 `SegmentJournal > persists the 10,000-line tail boundary and rebuilds a corrupt sidecar` 在两次全套运行中均达到 15 秒上限超时；单独运行该用例的测试耗时 2.17 秒并通过，所在完整文件单独运行 20 项全部通过。本次没有修改这部分代码和测试。
- 既有用例 `reports a failed Bypass respawn instead of presenting the Shell fallback as success` 在等待失败 RPC 时未通过；在本次改动前的代码上同样失败。本版与 0.2.16 一样，没有改动这部分 Claude 失败重启代码和测试。
- 历史范围性能和内存阈值：`recovers only the checkpoint suffix of a 32 MiB Journal within a 16 MiB RSS budget` 首次 p95 实测 173.15 毫秒，超过 100 毫秒阈值，单独完整重跑所在文件后仍为 182.16 毫秒；同组 `recovers only the checkpoint suffix of a 256 MiB Journal within a 16 MiB RSS budget` 在重跑时 RSS 增量为 17,088,512 字节，超过 16,777,216 字节上限。首次失败的相邻负载采样（1/5/15 分钟）为 27.81/36.14/31.51；单独重跑前后为 26.51/34.44/31.27 和 27.44/34.15/31.23。本次未修改相关实现、测试或阈值。
- Host control 端到端测试 11 项全部通过，覆盖真实 CLI 识别、读取/发送、新建会话、跨窗口导航、分支操作、一次性确认引用过期和消费。最终 arm64 安装包通过严格深层签名校验，以及 SQLite、PTY、历史回放、截断日志恢复和数据库兼容性冒烟测试。

## 下载与安装

- 适用于 **macOS Apple Silicon（arm64）**。
- 提供 DMG、ZIP、blockmap、更新清单和 SHA256 校验清单。
- 沿用现有 ad-hoc 签名方式，未使用 Apple Developer ID 签名或公证。macOS 首次打开可能需要在「系统设置 → 隐私与安全性」中允许。
- 本次发布更新 GitHub 下载包；应用内更新服务的部署与本机已安装应用的替换不包含在本次发布中。
