# 码头 Matou 0.2.16

## 更新内容

- 底栏 Agents 支持显示外部任务状态，并补充任务详情与状态停止更新提示。
- 精简账户用量展示，保留百分比与重置时间；缓存、登录异常和更新说明可在悬停及账户面板中查看。
- 新增「设置 → Claude Code → 时区」，支持跟随系统或指定时区，下次启动 Claude Code 时生效。
- 修复从其他 agent 终端启动码头时，独立 Claude 会话可能不保存后续对话的问题。
- 修复终端显示异常后的恢复，恢复显示时保留运行中的会话；减少历史回放的内存占用。
- 改进 Claude 续接确认、分支创建期间的状态反馈与焦点恢复。
- 修复 Claude 重启失败时可能提前显示成功的问题。

## 验证与已知限制

- 类型检查、命名检查、桌面 861 项单元测试及 3 项性能测试通过；账户专项 31 项 TypeScript、27 项 Python 测试通过。
- Runtime 常规测试 1148 项通过、1 项跳过；历史范围读取 9 项通过。
- 已验证时区保存与重启持久化、底栏展示和操作、账户切换、失败重启提示、终端显示故障恢复，以及官方 Claude CLI 连续重启后的对话保存。
- 最终 arm64 安装包通过严格深层签名校验，以及 SQLite、PTY、历史回放、截断日志恢复和数据库兼容性冒烟测试。
- 两项旧 Fork 全流程自动化用例仍在关系记录及失败卡片断言处未通过，不能视为这两条流程已完成完整验收。

## 下载与安装

- 适用于 **macOS Apple Silicon（arm64）**。
- 提供 DMG、ZIP、blockmap、更新清单和 SHA256 校验清单。
- 沿用现有 ad-hoc 签名方式，未使用 Apple Developer ID 签名或公证。macOS 首次打开可能需要在「系统设置 → 隐私与安全性」中允许。
- 本次发布更新 GitHub 下载包；应用内更新服务的部署与本机已安装应用的替换不包含在本次发布中。
