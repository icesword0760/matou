# 码头 Matou 0.2.15

## 更新内容

- 保留 Claude 账户一键立即切换、已有会话继续及切换后的可选「立即重启」，不增加登录步骤。
- 登录和凭据续期由官方 Claude Code CLI 处理。账户管理组件仅处理本地凭据保存、切换和回滚，不再自行联网查询身份、用量或续期。
- 用量读取官方 CLI 的状态栏数据并保存在本机。未使用账户显示上次记录；超过原始重置时间后标记「已到重置时间，待更新」，不把历史值当实时值，也不推算新的周期。
- 保留自动登录回调、粘贴授权码、重新登录引导；隐私浏览器窗口仍由用户自行关闭。
- 修复更新通道把较旧版本误报为可用更新的问题。

## 验证与边界

- 账户组件 31 个 TypeScript 用例、27 个 Python 用例通过；22 个 Electron 账户交互场景通过。
- 使用一次性真实 macOS 测试钥匙串、两个未修改的官方 CLI 和本地模拟服务，验证过期账户切入、官方续期、原会话继续、并发锁、凭据轮换保存及写入失败回滚。测试不代表真实服务端账户健康或风控结论。
- 完整安装包通过 SQLite、PTY、历史回放、日志尾部恢复及数据库兼容性冒烟；本机安装后工作区、会话记录、账户和 HUD 已核对。
- 现有 CLI 读取新凭据仍受其缓存影响；已经发出的请求保持原账户。可使用现有「立即重启」入口主动重启并续接。
- 被撤销的登录仍需重新登录；仅在外部终端使用时，或 CLI 未输出用量字段时，Matou 继续显示已有记录。

## 下载与安装

- 适用于 **macOS Apple Silicon（arm64）**。
- 提供 DMG、ZIP、blockmap、更新清单和 SHA256 校验清单。
- 沿用当前本地 ad-hoc 签名发行方式，**未使用 Apple Developer ID 签名或公证**。现有体验版通过应用内下载 DMG 后手动安装；不关闭签名验证。
- 此更新管理的是 Claude Code 本机默认登录，不包含 Claude 网页、Chrome 扩展或 Claude 桌面 App 的自动账户切换。
