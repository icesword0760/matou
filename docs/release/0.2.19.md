# 码头 Matou 0.2.19

这一版主要解决我自己天天碰到的几件烦心事：Claude 额度见底只能干等，换了网络线路不知道会话还安不安全，以及 Antigravity 得开一个单独窗口来回切。

## 用 ChatGPT 或 Antigravity 订阅接着跑 Claude Code

写到一半额度用完，手上明明还有 ChatGPT 或 Google AI 的订阅，却只能停下来，这种情况我遇到过很多次。现在可以在「设置 → 服务供应商 → Claude Code」里新增一个订阅账号，在浏览器登录一次，再点「切换」，Claude Code 就改由 GPT 或 Antigravity 里的模型来回答。

不需要 API Key，也不用自己去装转发工具，码头内置了。正在跑的会话会自动重启并接上原来的对话，我实测切换在 1 秒内完成。用 ChatGPT 账号时，Claude Code 的网页搜索和网页抓取照样能用，搜索由 OpenAI 执行，算在你的 ChatGPT 额度里。`/model` 菜单里显示的是真实模型名，不会出现一个让人摸不着头脑的 "Custom model"。

有几件事要先说清楚：
- 需要 macOS 15 或更高版本，更早的系统上这个入口是灰的。
- Google 的条款不允许第三方工具使用 Antigravity 账号，被判定违规可能停用账号。第一次添加时码头会弹窗提醒，请自己权衡。这一版的 Antigravity 账号接入没有用真实账号验收过。
- `/model` 菜单最上面的 Default 一行仍会显示 Anthropic 的价格，这是 Claude Code 自己写死的，我们改不了。

## 网络出口检测

码头不替你管代理，它做的是盯住每个官方会话实际是从哪里连出去的，出口国家显示在卡片底栏。终端没读到代理、分流规则漏了、节点中途换了，这些情况以前很难第一时间发现。

一旦确认出口不对，码头会先把正在运行的官方会话冻结，同时拦下新会话。屏幕内容保留，但这段时间敲的字不会发出去。网络恢复后它会自动复查，没问题就继续。提示条上有「重新检查」；如果判断错了，可以点「仍要继续」，或者直接在面板里关掉保护。官方会话启动时，系统时区会换成同为东八区的其他城市，时间读数和本地完全一样。用 ChatGPT 订阅驱动的会话也在保护范围内；DeepSeek、Kimi 这类第三方服务和普通 Shell 卡片不受影响。

## Antigravity 放进码头

在任意终端里输入 `agy`，这张卡片就变成 Antigravity 会话。它在工作、在等你审批、做完了还是出错了，卡片上都看得到。底栏显示模型、推理档位、上下文占用、5 小时和每周额度。`AGENTS.md`、`GEMINI.md` 可以直接从底栏打开编辑。

码头重启后会自动接回原来的对话。和 Claude 卡片一样可以 Fork 出子会话，子会话带着原来的上下文；本机以前的 Antigravity 会话也能从「载入会话」里直接打开。在 Antigravity 里用 `mt` 命令，可以查看和操作旁边的终端卡片。

## 小修复

- 子 Agent 名字太长时，现在会完整显示成两行，右边的用时不会被挤走。
- 会话启动失败的提示在窄卡片上不再挤成一个字一行的竖排。
- 打包时会自动检查运行所需的模块是否都在安装包里，避免装好后打不开。这一版发布前就靠这道检查拦下了一次。

## 验证与已知问题

这一版在合并后的完整代码上跑了回归测试，用真实 ChatGPT 账号走完了登录、切换、问答、搜索和切回官方，签名安装包也做了冒烟测试。

还有一个老问题没解决：在只读模式下恢复终端历史偶尔会失败，0.2.18 也有，我们还在排查。

## 安装

- 适用于 macOS Apple Silicon（arm64）。
- 提供 DMG、ZIP、blockmap、更新清单和 SHA256 校验文件。
- 使用 Developer ID 签名，没有做 Apple 公证。从旧签名版本升级时，可能需要重新授权一次目录访问。

# Matou 0.2.19

This release is mostly about a few things that kept getting in my way: running out of Claude quota mid-task, not knowing whether a session was still on the right network route, and having to keep Antigravity in a separate window.

## Keep Claude Code running on your ChatGPT or Antigravity subscription

If you've ever hit your Claude limit while a ChatGPT or Google AI subscription sat unused, this is for you. Add a subscription account under Settings → Service providers → Claude Code, sign in once in your browser, click Switch, and Claude Code now runs on GPT or on the models in your Antigravity plan.

No API key, and no separate proxy to install; Matou ships one. Running sessions restart and pick up the same conversation, and in my tests the switch takes under a second. With a ChatGPT account, Claude Code's web search and web fetch keep working; searches run on OpenAI's side and count against your ChatGPT quota. The `/model` menu shows the real model names.

Before you try it:
- It needs macOS 15 or later. On older systems the option is greyed out.
- Google's terms don't allow third-party tools to use Antigravity accounts, and a flagged account may be suspended. Matou warns you the first time; please decide for yourself. Antigravity sign-in was not tested with a real account in this release.
- The Default row at the top of `/model` still shows Anthropic pricing. That's hard-coded in Claude Code and outside our control.

## Network egress checks

Matou doesn't manage your proxy. It watches where each official session actually connects from and shows the exit country in the card's status bar, so a terminal that ignored your proxy, a routing rule that leaked, or a node that changed mid-session no longer goes unnoticed.

When the exit is confirmed wrong, Matou pauses running official sessions and holds new ones. The screen stays as it is, but anything you type during the pause isn't sent. Once the network recovers, Matou re-checks and continues on its own. The banner has a Check again button; if Matou got it wrong, click Continue anyway or turn protection off in the panel. Official sessions also start with a system time zone set to another UTC+8 city, so the clock reads exactly the same. Sessions driven by a ChatGPT subscription are covered too; third-party providers such as DeepSeek or Kimi and plain shell cards are left alone.

## Antigravity inside Matou

Type `agy` in any terminal and the card becomes an Antigravity session that shows whether it's working, waiting for your approval, finished, or failed. The status bar shows the model, reasoning effort, context usage, and 5-hour and weekly quota, and you can open `AGENTS.md` or `GEMINI.md` from there.

Sessions reconnect after Matou restarts. Like Claude cards, an Antigravity card can be forked into a child session that keeps the conversation context, earlier local Antigravity sessions can be opened from Load session, and the `mt` command lets Antigravity inspect and drive neighbouring cards.

## Smaller fixes

- Long sub-agent names now wrap onto two lines instead of being cut off, and the timer stays in place.
- The "session failed to start" banner no longer collapses into vertical text on narrow cards.
- Packaging now checks that every module the app needs is actually bundled, so an install can't fail to launch for that reason. This check caught a real problem before this release went out.

## Verification and known issues

We ran the full regression suite on the merged code, walked through sign-in, switching, chat, web search and switching back with a real ChatGPT account, and smoke-tested the signed package.

One older issue remains: restoring terminal history in read-only mode occasionally fails. It also happens in 0.2.18 and we're still looking into it.

## Install

- macOS on Apple Silicon (arm64).
- DMG, ZIP, blockmaps, update manifest and SHA256 checksums are attached.
- Signed with a Developer ID but not notarized by Apple. Upgrading from an older signature may ask you to re-authorize folder access once.
