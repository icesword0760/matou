# 码头 Matou 0.2.18

## 更新内容

- 启动时自动恢复最近使用的 16 条会话，其余卡片保留记录并显示手动恢复入口；切换画布不会偷偷启动未恢复的会话。手动恢复的会话会进入下次启动的最近使用排序。
- 降低空闲会话的后台开销：状态栏刷新不再重复查询 Git 和持久化相同的会话身份，Git 锁文件变化不再引发循环刷新；调整 macOS Claude 子进程的默认内存回收检查间隔，保留用户显式设置。
- 隔离启动环境中的调用方会话名称、身份和后台恢复参数，避免新会话继承其他会话的信息。后台占用导致恢复失败时显示具体原因。
- 返回长时间离屏的 AI 终端时，大量重绘积压改为恢复当前屏幕快照，完整历史记录仍保留；发送终端命令时等待输入回显稳定后再提交。
- 启动等待超过 1.2 秒时显示加载反馈，分支进度条使用 transform 动画，减少布局重排。
- macOS 安装包改用 Developer ID 签名，发布命令要求签名成功。后续保持相同签名身份，避免临时签名随构建变化而使目录访问授权失效。首次从旧签名迁移仍可能需要重新授权。

## 安装与分发

- macOS Apple Silicon（arm64），提供 DMG、ZIP、blockmap、更新清单与 SHA256 校验文件。
- GitHub Release 与应用内更新服务器发布同一组文件，更新清单最后切换。
- 本版使用正式 Developer ID 签名；发布环境尚未配置 Apple 公证凭据，不宣称已公证。

## 验证

类型检查、命名门禁、桌面 863 项单元测试及 3 项性能测试、Runtime 常规 1172 项与 RuntimeServer/边界专项 140 项通过；13 项场景端到端、真实 Claude 恢复和最终安装包冒烟通过。历史范围读取仍有 1 项内存门禁失败（256 MiB 日志恢复增量约 18.8 MiB，预算 16 MiB），不宣称全套通过。详细结果及首次失败/重跑记录见 [发布验收](../acceptance/release-0.2.18.md)。历史本地会话数据修复不包含在安装包中，用户聊天记录和本机诊断数据不上传到代码仓库。
