# Matou 云端更新设计规格

## 目标

为 Matou 桌面端增加 macOS 优先的整包云端更新能力。更新在后台发现与下载，不打断终端工作；安装前识别活动会话，默认等待空闲或退出时安装，并在重启后恢复持久化工作区。

## 用户交互

1. 顶部右侧始终保留紧凑更新入口。没有更新时入口保持弱化；发现新版本后显示蓝色状态和未读点。
2. 启动 15 秒后静默检查，之后每 4 小时检查一次。用户也可从更新浮层手动检查。
3. 发现更新时浮层展示版本、发布日期、安装包大小和最多 3 条更新摘要；用户主动开始后台下载。
4. 下载中展示百分比、已下载大小、总大小、速度和剩余时间；关闭浮层不停止下载。
5. 下载完成且没有活动会话时，主操作为“重启并更新”，次操作为“退出时安装”。
6. 下载完成且存在活动会话时，显示活动会话数量，主操作为“空闲后自动更新”，并保留“立即重启并更新”和“退出时安装”。
7. “空闲后自动更新”只在活动会话数降至 0 后执行；排队期间入口显示等待状态，可取消等待。
8. “立即重启并更新”先结束 Runtime 并等待持久化写入完成，再调用更新器安装。
9. 重启后检测应用版本变化，只显示一次“已更新”轻提示。
10. 检查或下载失败时保留当前应用版本，浮层展示可理解的错误和“重新检查”。

## 活动会话定义

未归档且 `workStatus` 为 `starting`、`running` 或 `needs-input` 的唯一会话均计入活动会话。`idle`、`interrupted`、`error` 和 `exited` 不阻止空闲安装。

## 更新状态协议

渲染器只消费不可变的 `AppUpdateState`：

- `idle`: 尚未检查。
- `checking`: 正在检查。
- `available`: 已发现版本，等待用户下载。
- `downloading`: 后台下载中，包含进度。
- `downloaded`: 已下载，可安装。
- `not-available`: 当前已是最新版本。
- `error`: 检查或下载失败。

状态包含当前版本；新版本状态还包含目标版本、发布时间、摘要和可选大小。下载状态包含百分比、字节数、速率和剩余秒数。

## 主进程边界

- 使用 `electron-updater`，关闭自动下载，开启退出时自动安装。
- 更新检查与安装仅由主进程执行；Renderer 通过类型化 IPC 获取状态、订阅变化并发送检查、下载、安装命令。
- 普通开发运行不访问更新服务器；打包应用启用真实更新。测试通过注入更新器适配器覆盖所有事件。
- 更新安装入口统一经过 Runtime 优雅关闭，避免终端和 SQLite 写入被截断。
- 所有主窗口都收到相同更新状态；任意窗口发起操作都作用于应用级更新器。

## 发布与服务器

- 第一阶段平台为 macOS arm64/x64，产物包括 DMG、ZIP、blockmap 和 `stable-mac.yml`。
- 更新源采用通用 HTTPS 静态目录；地址由构建环境变量 `MATOU_UPDATE_BASE_URL` 提供，默认占位 `https://UPDATE_HOST/matou/stable`。
- stable 为第一阶段唯一通道；`MATOU_UPDATE_CHANNEL` 保留为构建/运行配置，默认 `stable`。
- macOS 自动更新发行包必须使用 Developer ID Application 签名并完成 notarization。CI 从密钥环境读取证书和公证凭据。
- 服务器需支持 HTTPS、Range 请求、正确的 `Content-Length` 与缓存控制。更新清单必须先于客户端检查可见，发布时先上传二进制和 blockmap，最后原子替换清单。

## 安全与失败边界

- Renderer 不接触服务器凭据，也不接受任意下载 URL。
- 只安装签名校验通过且版本高于当前版本的产物。
- 下载失败可重试；安装失败保留当前版本。
- 更新浮层不会覆盖终端输入焦点；打开时按 Escape 或点击外部可关闭。
- `prefers-reduced-motion` 下关闭缩放和位移动画。

## 验收标准

1. Mockup 中四个核心状态在实际 Matou 顶部右侧可见并可操作。
2. 关闭浮层后下载继续，重新打开能看到最新进度。
3. 有活动会话时不会因“空闲后自动更新”立即重启；活动数归零后只触发一次安装。
4. 点击“立即重启并更新”先完成 Runtime 关闭，再调用更新器。
5. 打包配置生成更新清单并接受外部 HTTPS 更新地址。
6. 主进程状态机、IPC、渲染器交互均有自动化测试；全量 typecheck、unit tests 和 package build 通过。
