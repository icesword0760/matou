## 焦点修正后的定点复验

同一预览 URL 重新打开时浏览器仍读到旧版；在本地预览 URL 后加查询参数重新加载后取得修正版。以下结果取代上节中保存后焦点丢失的旧版结果：

- 初始、缺模型、账号失效、模型不可用时，保存按钮均为原生 `disabled=true`。
- 合法编辑后鼠标点击保存，成功提示立即出现；焦点保留在保存按钮，按钮 `disabled=false`、`aria-disabled=true`，外观禁用；点击前后 `window.scrollY=0`、`main.scrollTop=602`，未跳动。再次点击后反馈与状态无可见变化。
- 点击恢复默认后，三档均为默认，焦点保留恢复默认按钮，按钮仍可聚焦。
- OpenCLI 对合法、已聚焦的保存按钮发送 Enter 和 Space：两次操作前后焦点均为 `save-allocation`，`disabled=false`、`aria-disabled=false`，未出现保存反馈。这是本次工具观察，尚不能判断真实键盘是否有同样表现。
- 已更新 `saved.png`。复验结束已重置为初始混用及正常场景，页面与主设置区均回到顶部。
