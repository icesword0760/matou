# 本关决定与实现边界

本文件记录最终原型的决定；以 `index.html` 和浏览器证据为准。全部是本地原型，没有修改产品源码、真实配置或请求路由。

## 已确定方向的执行

- 保留现有 Claude Code 设置导航、header、供应商列表及影响提示。
- 唯一新增区域放在影响提示之后、对话压缩模型之前；压缩和派活的先后关系不变。
- 沿用当前源码的 workspace 颜色、系统字体、11/12/13px 字号、10px 卡片圆角、34px 控件及既有按钮和错误样式。
- 三档初始为 Opus → ChatGPT 演示账号 / GPT 演示模型 A；Sonnet → DeepSeek / DeepSeek 演示模型 A；Haiku → 沿用默认供应商 / Haiku 默认模型，明确最终是 Claude 官方。

## 主代理自行决定

1. 使用中性演示模型 A/B，不用具体 GPT、DeepSeek 或 Claude 版本号推断实际可用性。
2. 切换到显式供应商时清空旧模型，要求主动选择；避免保留跨供应商错配。
3. “恢复默认”将三档都改为沿用默认，仍需点击“保存分配”。
4. 保存仅更新页面内存，反馈即时；刷新或“重置演示”回到初始混用方案。不增加存储、延迟或依赖。
5. 模型不可用演示仅影响 DeepSeek 演示模型 A；B 可由用户主动改选恢复。账号失效时同步更新列表及对应行的假账号说明，不自动替换供应商。
6. 保存成功后以 `aria-disabled` 显示不可重复保存，同时保留按钮焦点；初始、缺模型和错误状态使用原生禁用。恢复默认按钮保持可聚焦。重复保存有内存状态校验保护。
7. 本机 `op` 不在 PATH，使用技能支持的本地 Bun 源码入口。辅助 checklist/extract 命令与技能文档不一致，本关保留 brief JSON，通过 attach/branch 登记，不调用付费生成。
8. DSH 长请求网络静默后先停止并核对产物；监督端明确要求不再等待后，停止后续请求，复用其已落盘界面并由主代理接上交互。没有重复活动任务或切换模型。

## 来自 DSH 界面骨架的决定，由主代理审查保留

1. 独立演示控制放在设置 stage 以外的底部文档流，避免浮层挡住设置。
2. 错误放在对应行、字段下方，复用现有错误色；保留行级和字段级状态。
3. 640px 以下三列表格改为逐档纵向排列，并显示字段标签，方便窄窗口阅读。

DSH 实际执行模型为 `deepseek-flash / high`。其骨架里曾出现的 Haiku 具体版本已由主代理替换为中性默认模型。

## 来自 Terra 浏览器验收的决定

- 用 Opus 改选 DeepSeek 演示模型 B 验证联动和保存；用独立演示控件验证失效，不涉及真实账号。
- 默认及编辑截图以完整展示模型分配和操作按钮为取景重点，另留 overview 展示 header 和完整列表。
- 如实区分持久视口下的 DOM 检查与临时截图尺寸的视觉检查，不把截图尺寸当成已完整操作的视口。
