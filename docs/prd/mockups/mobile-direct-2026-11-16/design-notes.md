# Matou 手机端：会话直达与关系切换

2026-11-16。范围：独立 HTML 交互原型，演示数据，不连接桌面运行时、不执行命令、不产生模型调用。

## 本轮产品选择

- 会话为日常入口。工作空间、事项、画布作为归属信息保留，用户可以从最近列表直接进入会话。
- 会话顶部区分归属路径与分支来源。切换面板区分当前分支与同画布其他会话，不将共同归属画布误表述为上下文继承。
- 事项/完整关系为可选入口；手机不修改桌面窗口及布局。
- 切换保留各会话草稿和阅读位置，返回沿访问路径回到原会话。
- 原型的运行状态、回复、文件改动与连接状态都是合成数据；不代表真实远程续接已经实现。

## 建议体验路径

1. 首页点「替代方案」，直接进入会话。
2. 输入一段草稿，不发送；向上滚动阅读历史。
3. 点「切换」，依次试主方案、弱网验证、测试，再回替代方案，检查草稿与阅读位置。
4. 点正文中的「打开测试会话」，查看结果后返回。
5. 展开其他画布进入「账户恢复」；查看归属路径与关系是否随之更新。
6. 回首页搜索与筛选，从工作空间入口按归属查找。

## 验收边界

本原型验证导航与局部状态保持，不是正式移动端实现，也不作为桌面 reference product 1:1 验收。真实手机触控/软键盘、网络断线重连、电脑休眠、双端并发输入、真实终端与账户授权仍未验证。

## 实际验证结果

- 在独立 Chromium 浏览器中实际操作：首页直达、来源/子分支切换、测试结果跳转和返回、跨画布/项目切换、完整关系、草稿与阅读位置保持。切换检查阅读位置为 140px；新消息到来时阅读位置保持 100px。
- 搜索、空态恢复、状态筛选、新建本地会话、模拟发送、重置、Escape/遮罩关闭、面板焦点隔离通过。
- 360/390/430px 下首页、对话、面板无横向溢出；已目视检查首页、会话、关系面板及桌面展示截图。
- file 直接打开并进入会话通过；localhost 服务仅展示此原型目录。
- JS 语法与仓库标识门禁通过。未运行全仓构建/测试（独立静态原型，无产品运行时代码变化）。详细记录见 verification.json。
