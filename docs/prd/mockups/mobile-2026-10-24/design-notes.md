# Matou 移动端页面设计 V1

日期：2026-10-24。范围：可交互的页面草图；不包含 APK、远程连接服务或真实账户操作。

## 设计背景

用户在外出时，希望用 Android 手机继续家里电脑上的 Matou 会话，包括查看进度、发送消息、处理确认，以及切换账户。用户已选择「浅色、简洁，延续桌面版」。本稿延续桌面版的蓝色操作、浅色背景、克制的边框和状态色，以清楚、安静、连续为设计方向。

## 页面与主要操作

1. 会话：优先显示需要回复的会话；支持按工作空间、状态筛选和搜索。项目、事项仍显示在会话归属中；进入对话后补全画布路径。
2. 对话：手机阅读排版，工具输出默认折叠；可展开原始终端。底部直接输入，账户和用量入口靠近输入区。对话里的信息只是合成设计数据。
3. 账户：展示已保存账户及 5 小时 / 每周用量，明确标注「家里电脑默认」。选择账户后说明影响范围，再执行立即切换；「立即重启并续接」单独处理。
4. 设备：显示家里电脑连接情况；离线时可回看已同步消息，草稿保留，发送与切换不能执行。恢复连接不自动发送草稿。
5. 操作确认：从通知或会话内直接处理需要确认的动作，保留允许和拒绝入口。

## 当前桌面行为基线

已读取当前账户面板源码 `apps/desktop/src/renderer/src/claude-accounts/ClaudeAccountsControl.tsx`，以及 `docs/acceptance/claude-accounts-immediate-switch.md`。README 中仍存在旧版「等任务结束再切换」描述，本稿采用当前源码的立即切换行为：

- 默认账户切换是电脑范围，包含该电脑上共享默认登录的终端和编辑器；API Key / 自定义供应商不在此范围。
- 不因任务运行而排队等待，不自动重启现有任务。
- 切换后的缓存生效可能延迟，不能以默认账户标签证明某次请求已使用新身份。
- 重启需要单独确认，可能中断任务；仅处理 Matou 内正在运行的 Claude 会话，并尝试恢复各自对话。
- 保留「已了解范围，下次直接切换」选择。

移动端是新增入口，不是已确认的桌面 PRD 1:1 验收。本稿不宣称通过 reference product 对照矩阵，不改动现有桌面行为。

## 本稿建议与待设计边界

- 第一版优先覆盖既有会话和已保存账户切换。新账户的手机授权流程尚未设计；原型内明确说明先在电脑添加。
- 对话结构化展示、消息推送、远程配对和设备授权均是产品方案，尚未实现或验证。需要后续结合真实会话输出、电脑休眠、家庭网络和连接中断场景确认。
- 配对建议首次在电脑旁完成，电脑端可撤销手机授权。手机操作的对象始终是明确命名的电脑。
- 原型中的终端、创建会话、重启、通知均为模拟交互；不访问真实账户，不执行命令，不申请通知权限。
- 跨设备同时输入、重连时消息发送结果不明、登录失效等边界需进入正式移动端规格。现有演示不代表这些边界已闭合。

## 查看方式

打开 `index.html` 查看三屏总览，点击「单屏体验」查看完整交互。手机宽度会自动变成一个全屏界面。可用 `?screen=device`、`?screen=offline`、`?screen=permission` 直接查看补充场景。

原型仅使用本地 HTML / CSS / JavaScript。所有账户名称、会话内容和额度均为演示数据，没有真实邮箱、密钥、电话或用户凭据。

## 原型检查

已在本地 Chromium 实际点击检查：会话搜索与筛选、发送示例消息、取消及确认账户切换、重启独立确认、离线禁用发送、恢复连接后草稿保留、操作确认后留在原会话。360 / 390 / 412px 视口未发现页面横向溢出，未捕获脚本异常。总览与补充状态已重新截图并目视检查。

设计检查报告的浅色文字对比度问题已修正；总览可见文字的计算检查未发现低于 4.5:1 的项目。原始对比度告警已修正。真实 Android 触控、软键盘、远程网络和 APK 功能不属于本稿已验证范围。

### 补充可读性检查

修正页面中小于 11px 的功能文字，包括账户用量说明、导航、状态、时间和设计板页脚；正文与页脚恢复正常字距，删除标题上方无信息增量的英文装饰行。

检测器把设备插画支架的 `border-bottom:3px solid` 识别成圆角卡片粗边框。这是显示器支架的绘图细节，并非卡片强调线；保留插画，针对该文件及该属性值登记局部豁免。未关闭整个规则或忽略文件。
