⌁默认会话：Shell · 当前工作空间目录 · 无额外选择

建议按此顺序体验

  1. 点击标题行“分支”图标并创建
  2. 点击分支状态徽章进入子会话组
  3. 悬浮会话，观察自动变宽
  4. 在任一会话输入内容并回车，观察它移动到最前且保持聚焦
  5. 横向滑到最左，向右拖拽返回
  6. 点击“＋”追加 Shell 兄弟；Shell 与 Claude Code 会显示在同一列表
  7. 在“持久化恢复”节点点击“重试恢复”，观察节点在原位置恢复 Claude Code
  8. 用 Claude Code 分支图标创建子节点或 Fork 兄弟
  9. 按住 Option + Tab 约半秒，打开会话 DAG
