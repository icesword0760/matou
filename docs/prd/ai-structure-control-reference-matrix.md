## 对照边界

- 本功能是在 Matou 现有终端、层级、会话画布、Worktree 与窗口行为上新增的 AI 结构控制能力。reference product 没有同名的 mt / Host Control 产品入口；因此下表的“reference 基线”以已确认设计 §14.2、既有 reference 交互结论和现存领域规则为准，不把 Matou 新增协议描述成 reference product 的既有能力。
- 所有截图均在目标状态完成后采集；截图证明用户可见结果，配对 JSON 记录断言、真实 Git / Runtime / 窗口状态。JSON 是补充证据，不代替截图。
- 自然语言场景使用 **deterministic local provider**，用于排除外部账号、网络与模型输出漂移；结构创建、窗口、Git Worktree、SQLite 持久化、provider 重启和 mt 均由打包 App 内的真实 Runtime 执行。
- “关闭画布”的既有最后画布规则是：最后事项的最后画布及会话受保护，窗口保持可见；只有用户关闭最后主窗口时才进入既有隐藏行为。
