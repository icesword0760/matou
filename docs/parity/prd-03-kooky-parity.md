# PRD 03 工作台信息：Kooky CLI 模块对照矩阵

## 验收口径

- 用户验收范围只包含黑色 CLI 模块中的工作区 / 事项侧栏及其反馈。
- 需求完整性以 `03-工作台信息.md` 为清单，视觉和交互细节以当前可运行 Kooky 与其现存代码为基线。
- Kooky Logo、产品全局导航和 Matou 自身窗口外壳不参与本项对照。

## 用户场景对照

| 用户场景 | Kooky 当前行为 | Matou 目标 | 验证方式 |
|---|---|---|---|
| 浏览事项 | 196px 黑色侧栏；顶部工作区行、`+ 事项` 行、事项列表 | 尺寸、颜色、间距、图标、文字和滚动行为一致 | 双应用截图 + computed styles |
| 切换事项 | 点击或 Enter / Space 切换；激活项为圆角深灰背景，无左侧蓝线 | 保持同样反馈，并仅清除新焦点面板已有未读 | 组件测试 + Electron 回放 |
| 新建事项 | 点击 `+ 事项`；新项追加到底部并激活；名称为 `新事项 / 新事项 2 / ...` | 一致，重启后仍保留 | Runtime 测试 + Electron 重启回放 |
| 重命名 | 更多菜单或右键 → `重命名`；420px 对话框；20 字计数；空名 / 重名红字；成功后轻提示 | 菜单、弹窗、键盘与校验一致 | 组件测试 + Electron 回放 |
| 删除事项 | 更多菜单或右键 → `删除`；`提示` 对话框；确认后清理事项内终端 | 一致；删除最后一项后自动补建 `默认` | Runtime 测试 + Electron 回放 |
| 拖拽排序 | 被拖项半透明 / 缩放，落位目标浅蓝；松手排序；当前事项不切换 | 一致，顺序持久化 | 组件测试 + Runtime 重启测试 |
| 未读反馈 | 有未读时显示红色数字徽标，`99+` 封顶；更多按钮被徽标取代 | 颜色、尺寸、优先级和上限一致 | 组件测试 + 外部错误日志回放 |
| 面板计数 | 数据函数存在，但模板中的计数元素已被注释，当前用户看不到 | 本轮不额外显示，避免偏离 Kooky 当前界面 | 源码证据 + 双应用截图 |
| 状态 / 进度 / 日志 | 仅提供外部写入数据通道，侧栏不显示明细；状态覆盖、进度覆盖、日志追加 | 保持无手工入口；空状态清除、进度钳制、非法日志隔离 | Runtime / Control 测试 |
| 错误日志 | 错误可进入通知路径并形成事项未读 | 外部错误写入后，不抢焦点地更新目标事项徽标 | Runtime 集成测试 + Electron 回放 |
| 长名称 | 单行省略，图标和右侧槽位不被挤压；当前条目未提供额外悬停浮层 | 保持当前 Kooky 行为，不额外增加浮层 | 组件测试 + 截图 |
| 菜单关闭 | Esc、点击菜单外、打开另一事项菜单立即关闭 | 一致 | 组件测试 + Electron 回放 |

## PRD 与 Kooky 当前实现的差异处理

1. PRD 多处写 `+ 新事项`，Kooky 当前 CLI 按钮显示 `+ 事项`；本轮采用 Kooky 当前可见文案。
2. PRD 描述激活态包含左侧强调线，Kooky 当前样式把左边框设为透明；本轮采用 Kooky 的圆角深灰激活态。
3. PRD 描述无未读时显示面板计数，Kooky 当前模板已注释该计数；数据能力保留，当前界面不显示。
4. PRD 描述蓝色未读徽标，Kooky 当前实际样式为 `#F54C46` 红色；本轮采用 Kooky 当前颜色。
5. PRD 同时出现“输入时实时校验”和“提交时校验”的表述；Kooky 当前重名随输入显示、空名通过禁用确认拦截，本轮保持其实际交互。

这些差异只影响呈现方式，不削弱事项切换、命名、排序、归属、外部写入和未读闭环。

  - 自动命名、同工作区重名拦截、激活事项持久化事件。
- `src/modules/terminal/stores/notification.js`
  - 事项未读聚合；状态 / 进度 / 日志的运行代数据通道。
- `src/modules/terminal/components/ClaudeCodeView.vue`
  - 新建事项与切换事项的实际调用链。
