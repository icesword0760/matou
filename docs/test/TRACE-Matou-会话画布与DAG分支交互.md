### 7.2 覆盖结论

- 每个功能点和验收场景均至少由一条 E2E 用例直接覆盖。
- 会话创建、关系、状态、导航、排序、结束和恢复均同时包含正向、边界与异常路径。
- 与用户数据安全相关的关闭、移除、工作树、异常退出和覆盖安装都要求真实文件系统与 Git 证据。
- 16 项规格问题均已在设计规格中形成唯一产品规则，E2E 执行以该规则为判断依据。
