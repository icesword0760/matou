# 目标解析

## 上下文优先

先运行 `mt identify --json`。明确 ref 或 session ref 直接使用；否则运行 `mt list --json`。

## 当前层级相对目标

- “左边/左侧” → `left`
- “右边/右侧/隔壁” → `right`
- “同级第 N 个” → `sibling:N`
- “父会话” → `parent`
- “第 N 个子会话” → `child:N`

左右和第 N 个只在调用方当前画布的当前 DAG level 内解析。父节点、子节点、其他画布或其他窗口不会混入同级序号。

## 名称与跨窗口

只有用户明确给出工作空间、事项、画布、标题、路径或跨窗口描述时，才运行 `mt list --all --json`。同时给出的名称、路径和序号都必须参与过滤。

匹配结果：

- 1 个：确认目标后执行。
- 2–5 个：列出标题、工作空间、事项、画布、profile、cwd 和序号，请用户选择。
- 超过 5 个：请用户增加一个筛选条件，不罗列长名单。

元信息仍不足时，可对少量候选运行 `mt read <ref> --lines 20`，但短读后若仍有多个候选，继续请用户确认。

## 连续指代

“它/那个/刚才那个”复用上一轮唯一且已确认的 ref。“另一个/左边那个/右边那个/换成 X”会使旧目标失效，重新 list 和解析。
